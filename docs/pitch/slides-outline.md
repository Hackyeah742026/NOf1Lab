# N-of-1 Lab — ≤10-slide pitch outline

1. **Title + team** — N-of-1 Lab · HackYeah SPORT & HEALTHCARE · [team name]
2. **Problem** — Watches, apps, training, mood, and tests scatter health data; people monitor but still don’t decide what to change.
3. **Insight** — Monitoring ≠ evidence. Personal lifestyle choices need short experiments, not another endless tracker.
4. **Solution** — N-of-1 Lab: pick a question → run A/B → log minimal signals → get Keep / Drop / Modify / Inconclusive.
5. **How it works** — Template → check-ins or CSV → deterministic stats engine → optional AI explanation of the same numbers.
6. **Category fit** — Sport (training load), physical health (sleep/caffeine), mental wellbeing (focus/energy), lifestyle decisions (delivery dinners).
7. **Demo** — Screenshots: Landing, 30s check-in, Result with computed verdict + AI explain.
8. **Tech value** — .NET Clean Architecture, SQLite, Result pattern, unit-tested analyzer; AI never invents figures.
9. **Usability + safety** — Demo login, seeded finished experiment, safety stop, explicit non-medical disclaimer.
10. **Ask / next** — Ship coaching loops, more templates, optional wearable CSV; ready for live pitch demo.

## Spoken mapping to judging criteria

- **Idea & Innovation (30%)** — Personal proof over passive tracking; verdicts from code.
- **Category (20%)** — Sport + body + mind + decisions in seeded templates.
- **Usability (20%)** — 30s check-in, clear verdict, one next action.
- **Design (20%)** — Calm Landing / Check-in / Result hero screens.
- **Completeness (10%)** — Working E2E demo, architecture, docs/demo script.
