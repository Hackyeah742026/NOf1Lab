# HackTribe submission checklist

Fill these fields in the HackTribe form before the deadline.

## Fields to fill

| Field | Notes |
|-------|--------|
| **Title** | Short product name (see suggested copy below) |
| **Team** | Official team name as registered for HackYeah |
| **Members** | Full names + roles for every teammate |
| **Description (EN)** | English pitch blurb (see suggested copy below) |

## Suggested title / description copy (N-of-1 Lab)

**Title:** N-of-1 Lab

**Description (EN):**

> Health apps flood you with charts but rarely answer “should I keep this habit?” N-of-1 Lab turns a lifestyle question into a short personal A/B experiment: pick a template, log a few check-ins (or import CSV), and get a computed Keep / Drop / Modify / Inconclusive verdict from code—not invented by AI. Optional Gemini narration only explains the same validated numbers. Demo-ready for sport, sleep, focus, and everyday lifestyle choices.

Adjust team/members to match your registration; keep the description English for judges.

## Screenshots to capture

Prepare clear product screenshots for the submission (and for the pitch deck):

1. **Landing** — brand + one-line value prop + CTA
2. **Active** — mid-run experiment with check-in / progress
3. **Result** — completed earlier-bedtime (or demo showcase) with computed verdict
4. **Templates** — catalog covering sport / physical / mental / lifestyle
